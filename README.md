# Caloricity

Название программы для ЭВМ: Программа для вычисления калорийности пробы по методическим указаниям 4237-86 "Caloricity".

Основным назначением программы является вычисление калорийности и количества белков, жиров, углеводов пробы, в соответствии документом МЕТОДИЧЕСКИЕ УКАЗАНИЯ ПО ГИГИЕНИЧЕСКОМУ КОНТРОЛЮ ЗА ПИТАНИЕМ В ОРГАНИЗОВАННЫХ КОЛЛЕКТИВАХ МУК 4237-86. Функциональность состоит из управления справочником ингредиентов, создания пробы, исследований к ней, прикрепление ингредиентов к ней, автоматическому вычислению калорийности, белков, жиров, углеводов, сухих веществ фактических и теоретических, сравнение результатов, формирование отчета в виде PDF. При запуске программы открывается консоль, а интерфейсом является браузер.
