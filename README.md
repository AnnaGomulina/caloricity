# Caloricity - Программа для вычисления калорийности проб

## Описание
**Caloricity** - программа для вычисления калорийности и нутриентного состава пищевых проб в соответствии с методическими указаниями МУК 4237-86 "Методические указания по гигиеническому контролю за питанием в организованных коллективах".

## Основные функции

### 1. Управление справочником ингредиентов
- Создание и редактирование базы пищевых ингредиентов
- Хранение данных о калорийности, содержании белков, жиров, углеводов на 100г продукта

![Ингредиенты](./Картинки%20работы%20программы/Ингредиенты.png)

### 2. Создание и управление пробами
- Формирование пищевых проб с указанием состава
- Прикрепление ингредиентов с указанием массовой доли
- Создание исследований
- Автоматический расчет:
    - Общей калорийности пробы
    - Содержания белков, жиров, углеводов
    - Сухих веществ (фактических и теоретических)
- Сравнение расчетных и фактических результатов

![Создание пробы](./Картинки%20работы%20программы/Создание%20пробы.png)

### 4. Формирование отчетов
- Генерация протоколов исследований в формате PDF. [Протокол](./Картинки%20работы%20программы/Протокол.pdf)
